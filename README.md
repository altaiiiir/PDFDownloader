# PDF Downloader

Download a PDF by pasting its link!

🌐 https://pdfdownloader-p4lh.onrender.com

## How it works
1. Copy a **direct PDF link**
2. Paste it into the box
3. Click **Download**
4. The PDF saves to your device

## Good to know
- The link must end in `.pdf`
- Private or blocked files won’t work
- No sign-up, no tracking, no clutter
